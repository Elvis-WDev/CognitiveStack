# Generated References

Use this directory for generated or mechanically derived documentation.

Examples:

- Database schema reference, generated from a freshly migrated SQLite database.
- Migration list, with version, name, and checksum.
- Use-case catalog, with inputs, results, error codes, and required permissions.
- External contract snapshots, such as sanitized HTTP payload samples or XSD versions.

Rules:

- Do not manually edit generated files unless explicitly documented.
- Regenerate them when source behavior changes.
- Keep generated docs small enough to be useful for agents.
