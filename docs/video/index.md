# Video Production Index

Rules for producing short animated videos that narrate a real operational problem, such as
the ones restaurants face every service, in a flat isometric style with subtle
micro-animations.

These documents govern video work. Where they differ from the web interface rules in
`../architecture/`, the video rules apply to video and the interface rules keep applying to
screens.

## Read Order

1. This file: the video brief and the non-negotiable style rules.

3. `isometric-style.md`: projection, geometry, color, light, characters, and composition.

6. `production.md`: formats, pipeline stages, rendering, audio, and deliverables.

## The Video Brief

Before writing a script or drawing a frame, answer seven questions in writing:

1. **Audience:** who watches, and what do they already know? Example: the owner of a
   40-table restaurant who has never used ordering software.
2. **Problem:** which single problem does the video narrate? One per video.
3. **Moment:** when does the viewer live that problem? Example: Friday, 9 p.m., full room.
4. **Cost:** what does the problem cost them, in time, money, reviews, or stress?
5. **Message:** the one sentence the viewer must remember after the video ends.
6. **Action:** what should the viewer do or feel at the end?
7. **Format:** channel, aspect ratios, duration, sound or muted, and language.

An unanswered question blocks production. Ask, or record the assumption so a reviewer can
correct it. Do not compensate for a weak brief with more scenes, effects, or text.

## Non-Negotiable Style Rules

| Rule                            | Meaning                                                                    |
| ------------------------------- | -------------------------------------------------------------------------- |
| One projection                  | True isometric, fixed camera angle, no perspective, for the whole film     |
| Solid color only                | Every fill is one flat color: no gradients, glows, blurs, or textures      |
| No borders                      | No outlines or strokes; edges come from contrast between solid faces       |
| One light                       | A single fixed light direction shades every object the same way            |
| Tokens, not values              | Colors, type sizes, durations, and easings come from documented scales     |
| Subtle micro-animation          | Small, slow, purposeful motion; nothing moves only to look busy            |
| One focal point at a time       | The viewer always knows where to look                                      |
| Readable muted                  | The story is understood with the sound off                                 |
| Problem before product          | The viewer recognizes the pain before any solution appears                 |

## Language

Write on-screen copy in the audience's language and locale. Keep the documents, scene
names, and code in English so every agent reads the same vocabulary.
